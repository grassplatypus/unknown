# 기본 목소리 묶음

이 폴더에 아래 이름으로 녹음 파일을 넣는다. 확장자는 `.ogg`, `.mp3`, `.wav` 중 하나이고, 같은 이름이 여럿이면 이 순서대로 앞의 것을 쓴다.
파일이 없는 줄은 소리 없이 건너뛴다.

| 파일 이름 | 말하는 때 |
|---|---|
| `raid_enter` | 정체 레이드에 들어갈 때 |
| `raid_exit` | 정체 구간을 지나 레이드를 나올 때 |
| `reward_ready` | P로 바꿔서 보상을 받을 수 있을 때 |
| `crops_ready` | 주행하는 동안 재배가 끝난 작물이 있을 때(P에서 재생). 대사: "주행하시는 동안 재배가 완료된 작물이 있어요!" |
| `postcard_new` | 새 엽서를 얻었을 때 |
| `field_drop_arrived` | 버섯 필드 드랍에 도착했을 때 |
| `level_up` | 레벨이 올랐을 때 |

이름은 `VoiceLine.kt`의 `fileName`과 같아야 한다. `VoiceAssetsTest`가 이 표와 enum을 맞춰 본다.

새 묶음은 `assets/voice/<묶음 id>/`에 같은 파일 이름으로 넣고, 화면에 보일 이름을 `pack.json`에 `{"name": "..."}`로 적는다. `pack.json`이 없으면 폴더 이름을 쓴다.
