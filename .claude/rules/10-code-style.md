# 코드 스타일

- 주석은 한 덩어리에 세 줄까지만 쓴다. KDoc은 태그(`@param` 등)마다 따로 센다. 더 길어지면 규칙 파일로 옮기고 코드에는 한 줄로 가리킨다.
- 주석에는 무엇을 하는지보다 왜 그렇게 하는지를 쓴다.
- 숫자 상수는 `BalanceConfig`에서 가져온다. 계산 함수는 config를 인자로 받아서 테스트가 고정값을 넣을 수 있게 한다.
- 화면 문구는 기능마다 따로 둔 `res/values/strings_<기능>.xml`에 쓴다. 한 파일에 모으면 여러 에이전트가 함께 고칠 때 충돌한다.
- Figma 픽셀 크기를 그대로 옮기지 않는다. 창 크기가 바뀐다(`20-architecture.md`).
